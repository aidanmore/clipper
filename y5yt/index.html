Run Y5YT on your Windows PC

Download and extract the clipper ZIP, then double-click start-y5yt.cmd inside y5yt. You need Python 3.10+ and your extracted FFmpeg build. Keep the launcher window open while a job runs.

When an episode has no transcript file, Whisper can generate one on your PC. Run py -3 -m pip install faster-whisper==1.2.1 once in PowerShell, then restart the launcher. Whisper downloads its model on first use.
